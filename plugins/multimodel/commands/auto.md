Вызови инструмент `auto_run` MCP-сервера ai-bridge с `task` = «$ARGUMENTS». Если задача про текущий проект, передай `work_folder` (абсолютный путь папки проекта) и названные в задаче файлы в `files`.

Покажи пользователю строку «Автовыбор: …» из ответа (какая роль выбрана и почему), затем сам ответ роли. Если мост советует консилиум, предложи `/multimodel:consilium` одной строкой.
