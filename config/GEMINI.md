# Global AI Duo & Claude Bridge Automation

У тебя подключен MCP-сервер `claude-bridge` (`claude_review`, `claude_ask`, `claude_implement`), связывающий тебя с установленным Claude Code.

Правила взаимодействия:
- **Orchestration Pattern:** Parallel Decomposition. При получении сложной задачи Antigravity ОБЯЗАН использовать инструменты `define_subagent` и `invoke_subagent` для параллельного запуска изолированных ролей (например, один агент пишет тесты, второй реализует логику в это же время).
- **Iteration Cap:** Жесткий лимит `max_iterations = 8` на одну подзадачу. Если субагент не решил проблему за 8 циклов, Antigravity обязан принудительно завершить его рантайм, зафиксировать ошибку и передать лог в `claude_ask` одной командой. В бесконечные циклы отладки не входить.
- **Context Pruning:** Запрещено передавать субагентам весь проект. Вырезать только целевые интерфейсы и спецификации. Субагенты должны получать контекст объемом не более 8,000 токенов.
- **Consilium & Fallback:** Архитектурный консилиум (`claude_ask`) проводить ИСКЛЮЧИТЕЛЬНО при создании новых модулей (`status: init`). При ответе `CLAUDE_LIMIT_REACHED` не блокироваться, продолжать работу самостоятельно.
- **Checkpoints:** Фиксировать контрольные точки через git commit перед масштабными изменениями.
