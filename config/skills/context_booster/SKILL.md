# Skill: Fast Codebase Context Retrieval (Ускоритель Контекста)

## Metadata
- **Name:** context_booster
- **Trigger:** model_decision (Активируется автоматически, когда пользователь просит "сделать проект", "отрефакторить модуль" или перед стартом крупной задачи).
- **Description:** Оптимизирует сбор контекста для мультиагентной системы, исключая долгое сканирование директорий.

## Instructions
1. Перед тем как начать планирование с Claude Code, сформируй плоский список зависимостей и целевых интерфейсов (Dependency Map).
2. Загрузи этот список в контекст сессии.
3. Передавай субагентам только этот плоский список файлов и релевантные фрагменты, запрещая им самостоятельно вызывать тяжелые рекурсивные сканирования всего корня проекта.
